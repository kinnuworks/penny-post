# Demo script

Three minutes, two phones, one take per scene.

The judges and the platform's reviewer read a transcript of this video, so anything that matters has to be said out loud. Say the names of the things being used: Mobile Wallet Adapter, SKR, Seeker Genesis Token, mainnet.

Every figure in square brackets is a blank. Fill it with the real number on the day of recording. If a number is not real yet, cut the sentence.

## Before recording

- The program is deployed to mainnet and the post office is open.
- Both phones have the release APK, a wallet with a little SOL, and the writer's phone has at least 40 SKR.
- The reader's phone has a letterbox, with the price you want on camera. Set it with "Change it" under the heading. If the writer's wallet has a `.skr` name, set it as the main name so it shows on the card.
- Do one full practice run, so the reader's token account exists and nothing on camera is a first-time prompt you have not seen.
- Record the phones with a camera on a tripod, hands in shot. A screen recording alone looks like a simulator.
- Upload your own captions to YouTube from this script. The platform prefers published captions over automatic ones, and automatic ones will not spell `.skr`.

## Script

### 0:00 The address nobody writes to

On screen: the reader's phone on a table, showing "Nothing today. The postman did look."

> Every Seeker came with an address, a dot S-K-R name. Nobody has ever written to one. This is Penny Post. It is a letterbox for your wallet, and the post comes once a day.

### 0:15 Writing a card

On screen: the writer's phone. Type the reader's name, take a photo, write the message with a finger, pick the Express stamp, post.

> I'm writing to [name] dot S-K-R. A photo for the front. The back I write by hand. The app has already looked the name up on mainnet, and it tells me the price before I sign anything: [10] SKR, which is what this reader charges a stranger. I'm using the Express stamp, so you don't have to wait for morning. One signature through Mobile Wallet Adapter. The postage is now in a vault on Solana mainnet that belongs to this one card and nothing else.

### 0:50 Signing for it

On screen: the reader's phone. A card is on the doormat, face down. Tap it, tap "Sign for it", approve in the wallet. The card turns over.

> On the other phone, a card is on the doormat. It is face down. I can see who sent it and that [10] SKR is inside. I tap "Sign for it". One signature, and the card turns over. [9] SKR is in my wallet now. The other [1] was burned. If I had ignored the card for a week, all of it would have gone back to the sender.

### 1:35 The free stamp

On screen: a Seeker, if one is available. Tap "I have a Seeker. Put my daily stamp on the counter." The header shows "Seeker No. [number]". Cut this scene if no Seeker is on hand, and say so in the written submission instead.

> If you own a Seeker, the app finds your Seeker Genesis Token and the program checks it on-chain. That earns one free stamp a day. The stamp is counted against the token, so one phone gets one stamp, however many wallets it makes. Friends write for free. Everyone else pays you.

### 2:05 Write to a stranger

On screen: the write screen. Tap "Nobody in mind? Write to a stranger." A name appears in the address field.

> Nobody to write to? Ask for a stranger. You get whoever has waited longest for a card, and you join the line for the next one. Send one, get one. And at eight tomorrow morning, the bell rings.

### 2:30 Why a builder should care

On screen: the doormat with a paid card on it.

> For builders, this is a way to reach Seeker owners that does not depend on an airdrop. Put a card in a verified letterbox, and pay only when a real person turns it over.

### 2:50 What is real

On screen: the repository's test output, then the program on the explorer.

> The program has [25] unit tests and [41] end-to-end tests, run against real SKR and a real Seeker Genesis Token. It is live on mainnet. [N] cards have been posted so far. Penny Post. The post comes once a day.

## After recording

- Check the transcript on the hackathon platform before the final submit, and fix anything it misheard.
